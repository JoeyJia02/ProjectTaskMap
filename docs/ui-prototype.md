# UI 原型与交互规范

实现入口：`src/ui/index.html`；组件：`src/ui/App.tsx`；独立任务树：`src/ui/TaskTree.tsx`。

运行 `npm run dev:ui` 后，默认显示真实项目连接表单；只有显式访问 `http://127.0.0.1:5173/?demo=1` 才显示标注为演示数据的可浏览原型。演示状态不会自动保存。原型即真实 UI 组件，避免静态图与最终功能偏离。

页面以白、浅灰、克制绿色构成：顶栏为项目身份、同步状态与刷新；四个视图为概览、任务树、决策日志、Parking Lot。概览首屏优先展示 Goal、Current Focus、明确下一步，随后呈现主线树与最近决策。受阻和暂存有文字状态，颜色仅作辅助。

树具有真实嵌套层次、连接线、展开/收起、活动分支路径。方向键、Home/End 浏览；左右键展开/收起或移动父子层级；Enter/空格打开详情。详情可修改标题、说明、下一步、状态和所属分支，维护前置依赖，查看证据。人工编辑使用 `/manual`；宿主发送的待写 delta 使用 `/deltas`。

恢复界面要求原绑定 key 与同一部署者凭据；token 只在页面内存，绑定 key 可放在当前浏览器 sessionStorage。MCP Apps 使用官方 App 桥、工具结果 `_meta` 中的短期凭据；存在 `window.openai` 时兼容其工具结果及 follow-up API。

刷新会请求 ChatGPT 输出可访问上下文的概况并调用 reconcile；界面明确显示等待，不在点击时假称完成。普通浏览器提供可选中复制的请求。已有状态在网络失败后保留；冲突单独展示，可批准或保留当前；历史可恢复为新版本；导出使用认证请求生成 Blob 下载，不在 URL 放置 token。

窄屏将目标/焦点和辅助卡片排列为单列；表单带标签、错误使用 alert、保存反馈使用 status；输入与可操作项有可见焦点，详情对话框支持 Escape 与焦点返回。测试记录以 `tests/ui.test.tsx` 为准；真实 ChatGPT 宿主连接需另行验证。
