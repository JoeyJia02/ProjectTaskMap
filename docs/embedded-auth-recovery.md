# 旧地图的一小时认证失效

2026-09-28 排查：本地 3000、临时 HTTPS 后端 3001 和公网健康检查均返回 200。用户截图显示 `Authentication expired or invalid`，不是网络不可达。

代码中打开地图时签发的 projectToken 只有 3600 秒有效期。此前 app-only 工具同时校验宿主 OAuth 和 projectToken 的到期时间；即使宿主 OAuth 已续期，旧页面仍携带过期 projectToken，所以自动读取只会重复失败。截图的通用错误无法单独排除宿主 OAuth 失效，但此代码缺口可稳定复现。

修复限定在通过认证的 MCP UI 工具：外层 OAuth 每次请求仍须有效；内层旧 projectToken 用作项目范围证明，继续校验签名、签发方、受众、项目、账号和相同授权 family，且 family 必须未过期、未撤销。满足这些条件时，页面凭据本身到期不再阻断读写。没有扩大任何项目权限，不自动重发写入。

独立 HTTP API 保持原有到期校验；篡改、其他项目、其他授权 family、撤销以及外层 OAuth 失效仍拒绝。需要重新授权的情况不能靠旧页面凭据恢复。

验证：97 项测试、类型检查和构建通过。新增集成测试模拟两小时后刷新外层 OAuth，用旧卡片读取、保存及幂等重试，并验证独立 HTTP 拒绝过期凭据、不同 family 不可续接、撤销不可恢复。真实客户端长时间使用仍需现场观察。
