详情页“网站：不可用”只表示没有配置插件官网链接，不是 MCP 连接状态；无需修复这一行。

1. 打开 **插件 → 个人 → Project Task Map**，查看详情中的连接或授权状态。若显示 **连接／授权／重新连接**，从这里发起授权；若已连接，直接执行第 3 步。若没有这些按钮，提供详情页状态再判断。

| 字段 | 填写内容 |
|---|---|
| 名称 | `Project Task Map` |

2. 如果下一页要求 **部署者访问密钥**，在项目文件夹双击 **复制任务地图授权密钥.cmd**，粘贴到该输入框，点击 **授权连接**。只在上表同一域名的授权页粘贴，不要发到聊天或截图里。
